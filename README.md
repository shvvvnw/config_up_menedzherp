# Dependency Visualizer

Конфигурационное управление, вариант 7. Реализованы этапы 1–3.

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 src/main.py
```

Настройки читаются из `config.yaml` в корне проекта. Путь тестового
репозитория отсчитывается от папки конфигурации.

`src/main.py` запускает программу, `configuration.py` проверяет настройки,
`repository.py` получает данные, `graph.py` выполняет обход и ищет циклы.
Все этапы используют один запуск через `src/main.py`.

## Этап 3

Используется DFS со стеком без рекурсии. Глубина корня равна 0.
При `max_depth: 0` выводится только корень, при 1 — его прямые зависимости.
Узлы на предельной глубине включаются, но их зависимости не запрашиваются.
Циклы определяются в построенной части графа; обход на них не зацикливается.
Если узел найден по более короткому пути, он обрабатывается повторно.

Текущая конфигурация использует `test_rapo.yaml` с циклом A → B → D → A.
Чтобы продемонстрировать разные случаи, в `repository_url` можно указать:

| Файл | Ожидаемый результат при корне A и глубине 3 |
| --- | --- |
| `tests/fixtures/cycle.yaml` | Цикл A → B → D → A |
| `tests/fixtures/acyclic.yaml` | Общая зависимость D, циклов нет |
| `tests/fixtures/self_cycle.yaml` | Цикл A → A |
| `tests/fixtures/missing.yaml` | Ошибка: B не описан |

Для этих примеров нужен `test_mode: true`. В тестовом файле ключи — имена
пакетов из больших латинских букв, значения — списки зависимостей.
Каждая упомянутая зависимость должна иметь свой ключ.

## Проверки

```bash
python3 -B -m unittest discover -s tests -v
```

Проверяются транзитивность, глубины 0 и 1, циклы, общий узел на более
коротком пути, цепочка из 1501 узла, неверный тестовый репозиторий
и запуск CLI вне папки проекта.

## Режим PyPI

Для реальных пакетов установите `test_mode: false`, `package_name: requests`
и `repository_url: https://pypi.org/pypi`.
Данные загружаются стандартными средствами Python, без pip или сторонних
библиотек для получения зависимостей. PyYAML нужен только для чтения YAML.

Строится граф всех объявленных зависимостей, включая дополнительные
и условные. Условия окружения и ограничения версий не вычисляются;
поэтому граф может отличаться от результата установки pip.
Отсутствие циклов утверждается только для исследованной части графа.
Параметр `ascii_tree` проверяется, его вывод относится к этапу 5.
