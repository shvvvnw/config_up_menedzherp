# Этап 5: визуализация

Дата проверки: 26 октября 2026 года.

## Проверка требований

1. `src/visualization.py` формирует текст D2 с узлами и направленными связями.
2. `src/main.py` всегда выводит этот текст в терминал.
3. При `ascii_tree: true` дополнительно выводится ASCII-дерево.
4. Сохранены три реальных примера: requests, urllib3, six.
5. Выполнено сравнение с pipdeptree в отдельном временном окружении;
   его фактический вывод сохранён рядом с примерами.
6. Изменения, тесты и примеры включаются в коммит пятого этапа.

## Представления

В D2 стрелка `A -> B` означает, что A зависит от B. Используются безопасные
идентификаторы `n0`, `n1` и подписи с исходными именами пакетов. Поэтому
имя с точкой не превращается в контейнер, а имя `direction` не заменяет
настройку диаграммы. Повторяющиеся рёбра выводятся один раз. Изолированные
пакеты, обратные связи и зависимости от самого себя сохраняются.

В ASCII используются только обычные символы веток. Циклы помечаются
`[cycle]`, повторы — `[seen]`. Если повторный путь короче, пакет может
быть раскрыт повторно, чтобы показать доступные на этом пути зависимости.
Граница анализа обозначается `[depth limit]`, в D2 также пунктирной рамкой.
Лист с такой отметкой не следует считать пакетом без зависимостей.

Для текущего циклического тестового репозитория дерево имеет вид:

```text
A
|-- B
|   `-- D
|       `-- A [cycle]
`-- C
    `-- D [seen]
```

## Сравнение с pipdeptree

Использовались Python 3.9.6 и pipdeptree 2.23.4. Пакеты установлены
в отдельное временное окружение `/tmp/config-up-stage5.GKnYyi/venv`.
pipdeptree применяется только для внешнего сравнения. Программа не вызывает
его и не использует сторонние библиотеки для получения зависимостей.
Это отдельный инструмент экосистемы pip, а не встроенная команда pip.

Для воспроизведения в новом временном окружении:

```bash
comparison_dir=$(mktemp -d)
python3 -m venv "$comparison_dir/venv"
"$comparison_dir/venv/bin/python" -m pip install pipdeptree==2.23.4 requests==2.32.5 urllib3==2.6.3 six==1.17.0
"$comparison_dir/venv/bin/python" -m pipdeptree --packages requests --warn silence
"$comparison_dir/venv/bin/python" -m pipdeptree --packages urllib3 --warn silence
"$comparison_dir/venv/bin/python" -m pipdeptree --packages six --warn silence
```

Результаты:

- **requests:** программа показывает 6 объявленных зависимостей;
  pipdeptree — 4 зависимости установленного requests 2.32.5.
  Общие узлы: certifi, charset-normalizer, idna, urllib3.
  Дополнительные pysocks и chardet в метаданных PyPI связаны с extras,
  которые при установке не включались.
- **urllib3:** программа показывает brotli, brotlicffi, h2, pysocks,
  backports-zstd. Все эти объявления обусловлены extras, а часть — также
  реализацией или версией Python. В установленном urllib3 2.6.3 без extras
  pipdeptree показывает один корневой узел.
- **six:** оба инструмента показывают один узел без зависимостей.

Кроме extras, отличаются выбранные версии. Во время проверки последние
версии PyPI были requests 2.34.2 и urllib3 2.8.0, обе требуют Python >=3.10.
В Python 3.9.6 pip выбрал совместимые 2.32.5 и 2.6.3. Для six обе стороны
использовали метаданные версии 1.17.0.

Программа показывает имена пакетов и все объявленные связи, не вычисляя
маркеры окружения и ограничения версий. pipdeptree показывает установленные
версии и применимые зависимости. Эти различия ожидаемы и не означают
ошибку преобразования одного фиксированного графа в D2 или ASCII.
Порядок соседних ветвей также может отличаться; сравниваются узлы и связи.
